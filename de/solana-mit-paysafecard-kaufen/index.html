SOL als Eintrittskarte

Jede Transaktion und jedes neue Token-Konto kostet auf Solana etwas SOL. Wer auf Jupiter tauschen, ein NFT prägen oder in einem frischen Wallet USDC auf Solana empfangen will, braucht zuerst ein SOL-Guthaben. Ein Code deckt das mehr als ab.

Solana-Adressen sind eine lange Folge aus Buchstaben und Zahlen ohne 0x davor und unterscheiden Groß- und Kleinschreibung. Immer kopieren.

Etwas SOL übrig lassen

Solana-Konten brauchen ein Mindestguthaben, die sogenannte Rent, und jedes Token belegt eine kleine SOL-Kaution. Wer sein ganzes SOL in ein Token tauscht, kann dieses Token später womöglich nicht mehr bewegen. Ein kleiner Rest im Wallet verhindert das.

Fragen zu Solana

Kann ich das SOL staken?

Ja. Phantom und Solflare lassen dich SOL direkt in der App an einen Validator delegieren.

Ist das USDC auf Solana?

Nein, hier geht es um SOL. Für USDC auf Solana USDC und das Solana-Netz wählen.

Den Umtausch wickelt ein externer Online-Umtauschdienst ab. Prüfe Kurs, Auszahlungsbetrag und deine Empfängerdaten im Formular, bevor du bezahlst.

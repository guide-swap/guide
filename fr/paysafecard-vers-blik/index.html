Code en euros, versement en zlotys

Un ticket acheté dans un tabac français est en euros, le compte chez PKO BP, mBank ou Pekao en zlotys. L'échange gère les deux d'un coup : vous choisissez EUR comme devise du code et BLIK comme destination, et le formulaire affiche le montant en zlotys avant le paiement.

Les virements BLIK fonctionnent 24 h/24, y compris le dimanche et les jours fériés polonais.

Bon à savoir

  • Uniquement vers des comptes de banques polonaises.
  • Les virements BLIK vers un numéro de téléphone doivent être activés dans l'appli bancaire.
  • Les codes en PLN achetés en Pologne sont aussi acceptés.

Paysafecard vers BLIK en cinq étapes

  1. Code ou compteCode pour un ticket, solde pour myPaysafe.
  2. Code, pays et deviseFrance et EUR ou Pologne et PLN selon le code, puis le montant.
  3. BLIK comme destinationLa devise versée est le zloty.
  4. Données BLIKLe plus souvent le numéro de téléphone enregistré pour les virements BLIK, comme indiqué dans le formulaire.
  5. PayerAprès confirmation sur la page Paysafecard, l'appli bancaire signale l'arrivée.

Le taux EUR/PLN

Avec un code en euros, c'est le taux EUR/PLN qui détermine le nombre de zlotys reçus. Il est figé dès que vous demandez le lien de paiement et ne change plus, même si le cours bouge avant que vous payiez.

Questions sur BLIK

Faut-il un compte en Pologne ?

Oui, BLIK ne fonctionne qu'avec les banques polonaises.

Montant minimum ?

20 euros, soit environ 100 zlotys.
